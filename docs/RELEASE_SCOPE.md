# Release scope

The public GPPAF source archive contains the four research algorithms, process-data preparation, training/evaluation programs, comparison methods, executable examples, unit tests and reproducibility metadata.

The integrated Unity3D engineering application demonstrates algorithm integration, robot-program export and automated-manufacturing workflow in the supplementary simulation video; its GUI/controller project is not part of this algorithm source archive.

Large solver-native FEA field databases/meshes and raw scanner point clouds are experimental source data rather than source code. They should be deposited with the article source-data record when required for figure-level reproduction. `gppaf/evaluation.py` provides the corresponding stress-field and point-cloud numerical metric routines used on exported arrays/tables.
